# 日枝 · FloraGrid

**让每一天，长出一点进展。**

每天事情一多总是忘，忙来忙去没头绪，工友你真得试试我这小软件。我给自己搞了一个桌面小工具，能分层次、打标签来管理每天的任务，今天没做完的事情也能通过复制挪到明天。此外，还提供了长期任务、生日纪念日提醒等功能。
对了，当完成任务打钩时，会开出一朵花，这是我们辛辛苦苦的奖励。
希望我们今日事今日毕，准点下班回家。

## 先照顾今天，再慢慢长大

把大事拆成小步，拖动调整顺序与层级；整棵任务树可以复制到另一天。完成时开花，收工时写一段随笔。

## 安排工作，也给生活留位置

月历看整月安排，全局搜索找回任务与随笔。公历、农历生日和周期提醒会按日期加入日任务。

![月视图：需求串讲、方案设计、代码编写、版本例会与上线变更，穿插学习、采购、跑步与生日提醒](docs/images/month.png)

## 把常做的事收好，随时开始

长期任务先收进库中，再加入今天或指定日期；每次安排都是独立记录。用分组标签整理不同生活领域。

![长期任务库：订单中心拆分、鉴权课程、力量训练与跑步计划](docs/images/long-tasks.png)

无需账号，数据保存在本机。支持多窗口、窗口置顶、精简外观，以及设置中的完整备份、恢复与文件夹迁移。

<sub>以上均为真实项目页面截图，演示数据围绕一位年轻后端工程师的工作与生活虚构生成，不包含私人记录。提醒是日任务，不是应用退出后的闹钟通知。</sub>

## 使用与开发

Windows 10/11 x64。安装版运行 Setup，免安装版解压后运行 `FloraGrid.exe`；两者默认使用同一份用户数据，需要 WebView2 运行时。

```powershell
npm ci
npm run dev
```
