# 日枝 · FloraGrid

<img src="src/assets/brand/logo.png" width="96" height="96" alt="日枝 Logo">

**让每一天，长出一点进展。**

把待办放在桌面，把大事拆成小步。日枝把日历、任务与随笔放在一起：常做的事收进长期任务库，整套任务连同子任务一起复制到另一天，生日和纪念日按公历或农历出现在日任务中。

无需注册，数据保存在本机。

## 主要功能

- **日视图与月历**：处理当天任务，查看一个月的安排，同时打开不同日期。
- **树状任务**：多层子任务、折叠、根任务标签、完成与失败记录、置顶和颜色。子任务标签数据与继承逻辑保留，界面入口暂时停用。
- **整树跨日复制**：保留标题、状态、标签、颜色和子任务结构；可粘贴到其他日期或作为子任务。
- **长期任务库**：先收集，再加入今天或指定日期；每次安排都是独立记录。
- **公农历重复提醒**：生日、纪念日、每年、每月或每周重复，生成真实日任务。
- **搜索与随笔**：搜索任务、标签、继承标签、每日随笔、长期任务与提醒。
- **自然的整理体验**：实时拖拽预览，任务平滑让位，支持层级调整和边缘自动滚动。
- **桌面外观**：五套自然主题、十种随机花型与柔和花色；任务沿曲枝生长，月历以每周枝条连接日期。可切换精简外观保留原对勾与配色。支持透明度调整、窗口置顶、托盘和多窗口复用。

## 开发与构建

项目使用 Tauri 2、Rust 和原生 JavaScript，需要本机已具备 Windows Tauri 构建环境。

```powershell
npm ci
npm run dev
```

构建 Windows 安装包：

```powershell
npm run build
```

NSIS 安装包默认输出至 `src-tauri/target/release/bundle/nsis/`。

## 数据与备份

在“设置 → 数据”查看实际数据目录。退出应用后备份整个目录，可以保留日任务、随笔、长期任务、长期标签和提醒规则。换电脑时复制数据，再在新电脑中选择该目录。

切换存储位置不会自动搬运数据。主题透明度等界面偏好存储在应用偏好中，与日程数据目录分开。
