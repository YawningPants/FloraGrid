# 日枝 · 品牌与图标

## 品牌

- 中文名：日枝。
- 英文名：FloraGrid，延续现有仓库名称。
- 标语：让每一天，长出一点进展。
- 产品名用于窗口、托盘、应用资源和后续安装包；应用标识 `com.example.desktop-calendar` 保持原值，以保留既有数据路径。Rust crate 与内部存储键同样保留兼容性。

## 图形与颜色

Logo 以日历与枝芽组成，枝芽兼具完成勾的轮廓。主体为深青、暖白、雾青三个色系，图形没有文字，以便在任务栏小尺寸显示。

应用默认图标由 Tauri 配置加载；新窗口继承该图标，托盘也使用同一默认图标。窗口左上角与浏览器页签使用同源 PNG。

原图由内置 imagegen 生成；尺寸转换与 ICO 导出使用本项目安装的 Tauri CLI，没有手工重画图形。

## 重新生成尺寸

在项目根目录运行下列命令，将导出结果放进构建目录；再从中复制需要的 ICO、PNG 到上表对应位置。移动平台的额外输出不需要加入本 Windows 项目。

```powershell
node node_modules/@tauri-apps/cli/tauri.js icon src/assets/brand/logo-master.png --output src-tauri/target/icon-build
```

图标与原生资源需要重新编译程序后生效。已安装旧版本通过新安装包更新；Windows 已固定快捷方式若仍缓存旧图标，可取消固定后重新固定。

## 生成记录

- 模式：内置 imagegen，`logo-brand`。
- 透明背景：开启，保留母版 alpha。
- 选用：一次生成的日历枝芽图形。
- 母版：1254 × 1254 像素，RGBA PNG；ICO 包含 16、24、32、48、64、256 像素帧。
- 验证：浅色、深色背景下检视小尺寸；窗口图片成功加载；从独立文件名编译的 Windows EXE 提取出新图标，文件资源中的 ProductName 与 FileDescription 均为“日枝”。原有调试 EXE 被系统锁定，验证未替换该文件。
- 提示词（原文）：

```text
Use case: logo-brand
Asset type: production Windows desktop app icon and logo mark for 日枝 / FloraGrid, a calm, personal desktop calendar with nested tasks, reusable long-term task templates, reminders and daily notes.
Primary request: Create ONE polished, simple, recognizable app icon: a warm ivory calendar-page silhouette whose interior incorporates one elegant branching sprout/checkmark symbol, suggesting daily progress and subtasks growing from a main task. Make the calendar and sprout a single coherent designed symbol, not separate clipart pasted together. Two short broad binding marks at the calendar top, only two simple leaves/branches; generous negative space and bold geometric shapes that remain clear at 16–32 pixels.
Style/medium: crisp flat vector-like graphic, thoughtful contemporary desktop productivity branding, softly rounded geometric edges, precise symmetry and optical balance. No texture, no photorealism.
Composition/framing: square 1024x1024 canvas. One centered rounded-square dark jade tile occupies about 90% of canvas with genuinely transparent pixels outside its rounded corners. The main ivory mark occupies about 64% of tile width; restrained sage/seafoam detail inside. The complete graphic is front-facing, flat and fills the frame appropriately for an app icon.
Color palette: deep jade #22343A, warm ivory #EDF3EF, soft seafoam #83B8B3. High silhouette contrast. At most these three colors, no busy gradients.
Text: no text, no letters, no numbers, no Chinese characters.
Constraints: deliver only the icon, no mockup, no presentation sheet, no duplicate alternatives, no watermark, no perspective, no ground shadow outside the tile. Transparent outside the rounded-square tile. Avoid thin strokes and tiny decorative details. Original abstract mark with no imitation of any existing app logo.
```
