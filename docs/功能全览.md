# 日枝 · FloraGrid：完整功能清单

> 基于当前代码核对的用户功能清单，供产品介绍、README、发布说明和使用手册取材。文中的“提醒”指按日期自动加入日任务。

## 一、产品定位

日枝是一款面向个人使用的 Windows 桌面日程工具，将日历、树状任务、可复用的长期任务、生日与周期提醒、每日随笔放在同一套工作流里。

核心过程是：先记下来，拆成小事，安排到某一天，记录结果，之后还能找回来。数据保存在本机，日视图和月视图可以同时打开。

## 二、日视图：专注处理某一天

- 每个日期拥有独立的任务和随笔；可以查看过去、安排未来。
- 显示日期、星期以及今天标识。
- 通过左右箭头切换前后一天；离开今天后显示“回到今日”图标。
- 切换日期和回到今天都在当前日视图内进行。
- 从月历、搜索结果等入口打开日视图，能够复用已经打开的目标日期窗口。
- 当前窗口切到一个已打开的日期时，先保存原目标窗口的内容，再收起它，由当前窗口接管，避免同一天出现两个可见日视图。
- 新建顶层任务、点击标题编辑、输入时自动保存；Enter 结束编辑，失去焦点结束编辑。
- 空白新任务会被清理。日任务编辑中的 Esc 用于退出编辑或取消空白项，并非通用的“撤销文字修改”。
- 日视图搜索当前日期的任务标题，包含子任务；匹配子任务时保留必要的父级上下文。
- 顶部固定显示进行中、已完成、已失败、已删除四类数量，统计包含子任务。
- 隐藏默认滚动条；有未显示的上方或下方任务时显示对应方向箭头，点击箭头可继续滚动。
- 状态统计位于滚动区之外，容器透明；滚动任务不会遮住统计。

## 三、树状任务：把大事拆成可推进的小事

- 任务可以添加子任务，子任务还可以继续细分。
- 通过层级缩进、树枝连线和折叠箭头表达父子关系。
- 支持展开、折叠子任务，折叠状态会保存。
- 新建子任务后自动展开父级，并将新任务滚动到可见位置。
- 子任务会显示沿父级继承的标签，同时可以拥有自己的标签。
- 父级标签和子任务自身标签保留来源区别；继承标签的来源可在悬停时辨认。
- 只有进行中的任务可以编辑标题、添加子任务及使用其对应编辑操作。
- 任务支持置顶，置顶在所属状态分组内生效；它与整个窗口的置顶是两个独立操作。
- 自定义颜色作为任务的识别线索；完成、失败仍有各自清晰的状态颜色和划线。

## 四、任务状态、恢复与删除

| 状态 | 能做什么 | 主要规则 |
| --- | --- | --- |
| 进行中 | 编辑、拆分、加标签、改色、排序、标记结果 | 默认的新任务状态 |
| 已完成 | 查看、重新改为进行中、复制、置顶、删除 | 显示完成标记和清晰划线 |
| 已失败 | 查看、恢复进行中、复制、置顶、删除 | 显示失败标记和状态配色，不允许拖动 |
| 已删除 | 在“显示已删除”中查看、恢复、彻底删除 | 默认隐藏，不允许拖动 |

- 任务按进行中、已完成、已失败、已删除排序，同状态内再考虑置顶与手动顺序。
- 父任务还有进行中的后代时，会提示先处理子任务，不能直接标记父任务完成。
- 完成一个带子任务的父任务时，会自动折叠其子任务。
- 将父任务标记失败时，进行中的后代也会变为失败；已经完成等其他状态保留。
- 恢复失败任务时恢复选中的这一项，后代的失败记录不会被批量抹去。
- 普通删除是软删除，记录任务被删除前的状态；恢复时尽量回到原状态。
- 删除父任务后，整个分支在正常视图中隐藏；打开“显示已删除”后可处理该分支。
- 彻底删除会移除选中的任务及其子任务，并提供确认步骤。

## 五、特色功能：跨日期复制、粘贴整棵任务树

### 复制入口

- 日视图任务右键“复制”。
- 月视图任务预览右键“复制”。
- 长期任务右键“复制”。
- 非删除状态的日任务可以复制，包括已经完成或失败的任务。

### 粘贴位置

- 另一个日期的日视图空白处右键，粘贴为顶层任务。
- 日视图任务右键中的“粘贴”，同样加入当天顶层。
- 在进行中的父任务上右键，可“粘贴为子任务”。
- 在月历目标日期上右键粘贴，不必先打开那天的日视图。
- 同一份内容可以继续粘贴到其他日期，不会移动原任务。

### 保留与独立性

- 复制的是当时的快照，后续修改原任务不会改变已经复制的内容。
- 保留被复制任务及其子树的标题、状态、颜色、自有标签、置顶和折叠等信息。
- 整棵子树的每个任务都会生成新的 ID，粘贴后成为独立记录。
- 从父级继承、但不属于被复制子树自身的数据，不会额外写入该快照；粘贴后的标签继承遵循新的父子关系。
- 复制已完成、失败任务会保留对应状态，不会自动清空进度。
- 从重复提醒复制出来的任务成为独立任务，不会复制原来的重复规则。
- 普通日任务不能粘回原日期，避免在同一天误复制；长期任务作为无日期来源，可以安排到任意目标日期。
- 使用应用内部、跨窗口共享的任务剪贴板；重新复制会覆盖上一次内容。这里的“复制粘贴”是结构化任务操作，不是系统文本剪贴板或已实现的 Ctrl+C / Ctrl+V 快捷键。

## 六、特色功能：长期任务库

- 长期任务是不绑定某一天的全局任务清单，入口位于月视图右上角。
- 适合先收集“以后要做”“有空时做”以及经常需要手动安排的事项。
- 支持新增、点击编辑、保存、取消、Enter 保存、Esc 取消和移开焦点保存。
- 支持临时标签与按分组选择的长期标签。
- 已有标签持续显示；添加标签入口在悬停、键盘聚焦或标签弹层打开时出现。
- “加入今天”常驻显示，直接将该项安排进今天的日任务。
- 右键“加入指定日期”，可以先选日期再安排。
- 安排之后，原长期任务仍留在库中，之后可以再次使用。
- 每次安排创建独立的进行中任务并带上标签；之后完成、改名或删除其中一份，不会同步修改长期任务模板或其他日期的记录。
- 长期任务列表支持拖拽排序。
- 支持软删除、显示已删除、恢复、彻底删除。
- 可通过全局搜索查找名称和标签，结果会回到月视图并定位该项。
- 当前长期任务库采用平面清单；需要细分的层级任务可以在日视图中建立，再通过整树复制复用。

## 七、拖拽：实时看见整理后的结果

- 拖起时原位置变灰，并显示被拖动任务的预览。
- 其他任务会平滑移动，为预计落点让出位置。
- 放下前就能看到结果位置；松开才提交并保存。
- 可以上下改变顺序，也可以结合横向移动调整任务层级、缩进或移出父级。
- 拖动父任务时，整棵子树一起移动。
- 折叠父级及其标签继承在拖拽预览中保持正确关系。
- 接近滚动区域上下边缘时可自动滚动。
- 拖拽中的 Esc、设备取消事件或在无效区域松开，都可以取消此次移动。
- 无效位置使用柔和提示，不采用突兀的红白禁止图标。
- 已失败、已删除的任务不能拖动；搜索过滤期间不允许拖拽。
- 已完成任务可以在允许的同状态范围内整理；拖动不会悄悄改变任务状态。
- 不允许放进自身或自己的后代；新建子级落点需要符合父任务状态规则。
- 长期任务采用同样的预览和移动体验，但保持平面清单。

## 八、标签：临时记录与长期分类

### 临时标签

- 在任务上随时填写文字、选择颜色并添加。
- 不需要先创建模板或选择分组。
- 可从任务上移除自己的标签。
- 临时标签与任务一起保存。

### 长期标签与分组

- 在设置的“长期标签”页集中管理，日视图与月视图入口共用同一管理窗口。
- 默认提供工作、生活、学习等分组和常用标签，可按自己的习惯调整。
- 分组与其中的标签放在同一张卡片里，直接看见归属。
- 支持创建、重命名、展开、折叠、删除分组。
- 支持在分组内新增标签、编辑名称和颜色、删除标签。
- 新增标签输入框默认隐藏，点击对应分组的添加入口后才出现。
- 单击标签编辑，长按拖拽排序；分组也可以重新排序。
- 色点表示正在编辑的标签颜色，点击可打开紧凑调色盘。
- 支持保存、取消、Enter 提交、Esc 退出相应编辑或弹层。
- 空白名称会被阻止并提示；最后一个分组不能被删除。
- 保存失败保留当前输入，方便重试。
- 标签选取器保留分组结构，分组较多时分页；长名称和弹层会适应窗口空间。
- 使用长期标签时复制一份标签快照到任务。修改或删除模板不会改写过去任务上的标签。
- 不同窗口会刷新已保存的标签修改；设置页切换标签、主题和数据页时，已有草稿、颜色、折叠与滚动位置会保留。

## 九、月视图：看清一个月的安排

- 月历占据主要空间，展示当月日期、今天高亮和相邻月的补齐日期。
- 周一为一周起点，按实际需要显示 4、5 或 6 周；不会固定多占一周。
- 日期格均分可用高度，随窗口大小调整。
- 使用左右箭头翻月；点击月份输入年月可跳转；离开当前月后可快速回到当前月。
- 日期格显示当天的顶层任务预览，任务颜色、完成和失败状态与日视图对应。
- 预览数量随日期格高度调整，最多 8 项；未展示的任务以剩余数量提示。
- 点击日期打开或复用对应日视图；点击任务预览可定位到那项任务。
- 任务预览支持右键复制；日期格支持粘贴和“为这一天添加提醒”。
- 长期任务、提醒采用按需展开的右侧工具抽屉，减少对日历空间的占用。
- 点击关闭、再次点当前入口或点击外部收起抽屉；点击日期时仍正常打开该天。
- 右上角四个入口统一为图标，悬停或键盘聚焦时显示居中的浅色名称提示。
- 当前月历未提供开启农历日期附加显示的用户入口；“支持农历”主要指重复提醒日期规则。

## 十、全局搜索：按日期和内容找回记录

- 月视图放大镜打开全局搜索，界面切换为结果列表。
- 默认搜索包含今天的最近 30 天，可选本月、最近 90 天和自定义起止日期。
- 搜索日任务、任意层级子任务、任务标签、继承标签、当日随笔、提醒任务和无日期长期任务。
- 可选择要搜索的内容类型；已完成、已失败记录默认包含，已删除记录需要勾选。
- 多个空格分开的关键词需要同时匹配，不区分大小写，并高亮匹配内容。
- 结果按日期分组，子任务带父级路径，随笔展示命中附近片段。
- 无日期长期任务可以被搜索到，不受某个日文件是否存在影响。
- 未来尚未打开过的提醒日期也可根据规则检索，点击后生成并打开对应日任务。
- 点击日任务结果打开对应日期并定位；必要时展开父级，显示短暂定位高亮。
- 点击随笔结果定位到该天的随笔。
- “月历定位”返回对应月份并高亮日期。
- 点击长期任务结果回到月历、展开长期任务并定位。
- 离开搜索后保留关键词、范围等状态；再次点放大镜可继续查看。
- 结果较多时分批显示，支持继续加载。
- 日期范围错误会提示；自定义范围控制在 100 年以内。

## 十一、生日、纪念日与周期提醒

### 创建和展示

- 可选择生日、纪念日或周期事项类型。
- 支持公历、农历，每年、每月和每周重复；每周可勾选多个星期。
- 可指定开始日期、任务颜色和生成后的任务置顶。
- 可使用预设色或自定义提醒颜色。
- 入口包括月视图提醒抽屉、日期格右键、设置中的提醒管理。
- 列表分为进行中和已停用，显示重复规则和下一次日期；可直接打开下一次对应的日视图。
- 到日期后作为真实的日任务出现，带生日、纪念日或提醒标识，并有专门卡片样式。
- 生成的任务同样可完成、失败、统计、拆分、添加标签、改色和整理。
- 任务上的提醒标识或右键入口可返回该规则管理。

### 日期规则

- 公历每月 31 日遇到没有 31 日的月份，使用当月最后一天；29、30 日遇到短二月也回退到有效月底。
- 公历 2 月 29 日的年度提醒，平年安排在 2 月 28 日。
- 农历 30 日遇到小月时在 29 日提醒。
- 普通农历月份的年度提醒不会在对应闰月额外重复一次。
- 闰月年度提醒在当年没有对应闰月时，使用同名普通月。
- 农历每月提醒包含闰月。
- 只有所选日期可能不存在时才显示相应解释，并写明回退日期。

### 历史、修改、停用和删除

- 新提醒从启用日期开始，不反向补创建之前的记录。
- 应用重新打开时补齐启用期间到今天应生成、但尚未生成的任务。
- 多窗口生成会去重，同一规则同一天不会反复添加。
- 删除某一天的单次提醒任务只取消这一次，之后不会因刷新或切月重新出现。
- “以后不再提醒”保留今天和过去的记录，从明天起停止自动添加。
- 未来尚未改动的自动任务会撤销；未来已经编辑、排序、添加子任务、完成或失败的任务会保留为独立任务。
- 内容和日期调整从明天生效；仅调整颜色、置顶从当天生效，已经处理过的任务仍受保护。
- 已停用规则可恢复，从新的开始日期继续，不补停用间隔。
- 已停用规则支持确认后彻底删除；已生成的今天和历史任务仍保留。
- 停用、删除或多窗口旧编辑不会把已经撤销的未来任务重新生成。
- 未操作的新增提醒页关闭后回到列表；有实际输入的草稿保留，保存失败也可继续编辑。
- 表单内容单独滚动，保存、取消固定在底部。

## 十二、每日随笔

- 每天都有独立的“今日所思所想”文本区。
- 适合保存会议线索、临时想法、学习记录和当天复盘。
- 随输入自动保存，失去焦点时立即提交。
- 可拖动分隔位置调整随笔区高度。
- 随笔可参与全局搜索并从结果直接定位。
- 当前是纯文本随笔，没有富文本、附件或 Markdown 编辑器。

## 十三、桌面窗口与托盘

- 日视图、月视图、设置可以独立打开，方便同时查看不同日期。
- 支持拖动窗口、调整窗口大小、最小化。
- 日视图、月视图支持窗口置顶，适合与编辑器、文档等并排使用。
- 窗口间按相对位置和可用屏幕空间安排，尽量邻近来源窗口，并对多个日视图进行错开和边界约束。
- 相同日期窗口、月视图和设置会尽量复用，设置中的长期标签也使用同一个编辑器。
- 日视图和月视图的任务变化会互相刷新；主题、长期标签、存储位置和提醒修改也有窗口间通知。
- 系统托盘支持打开今日日程和退出应用；托盘指向实际拥有今天日期的窗口。
- 主日视图关闭后隐藏到后台；其他工具窗口可关闭。日视图空闲时按 Esc 可隐藏窗口，编辑、搜索、弹层或拖拽中的 Esc 优先处理当前操作。
- 窗口提示不挤动按钮位置，弹层尽量留在当前可用屏幕范围内。

## 十四、主题与颜色

- 两种外观：默认“日枝”外观，以及保留原来对勾、连线和配色的“精简”外观。在设置 → 主题 → 外观中切换。
- 日枝外观的五套主题：枝间雾、雨后蓝、杏色光、苔庭绿、暮花粉。花瓣、花心、枝叶、完成绿和失败红随主题搭配。
- 精简外观保留五套原主题：海雾青、暮云蓝、暖杏棕、松影绿、雾玫灰。
- 日枝外观完成任务时，在原按钮处展开一朵五瓣小花，约 0.42 秒后平滑归位；月历以同款静态小花表示已完成。已有完成记录也显示花朵，加载和刷新不重播动画。
- 开花不改变任务状态规则和数量统计；子任务未处理完时仍不能完成父任务，失败和删除继续使用原来的中性状态标记。
- 可以单独关闭开花动效，保留静态小花；也尊重系统的“减少动态效果”偏好。
- 树状连线带有轻微弧度和叶尖；整枝完成时有一次短反馈，粘贴任务时有短暂的新叶提示。
- 长期任务和空白日期使用小枝芽空状态，每日随笔标题加入枝芽点缀。精简外观隐藏这些装饰。
- 本轮没有加入花田、月年花朵统计或持续摇摆、粒子效果。
- 主题可实时预览、保存，并同步到打开的其他窗口。
- 支持 34%～100% 的透明度滑块，默认 84%，可调到完全不透明。
- 支持恢复默认主题。
- 任务可从紧凑调色盘选择 8 种颜色，或通过图标恢复无自定义色。
- 自定义任务色、完成的绿色、失败的红色与主题色配合，避免多种颜色同时大面积抢占卡片。
- 标签拥有独立颜色；重复提醒也有自己的颜色和置顶设置。
- 添加标签等次要任务操作按悬停或聚焦显示，日常界面保留任务内容和主要入口。
- 图标、输入焦点、按钮和弹层采用统一的圆角、主题细边框和轻量提示样式。

## 十五、本地数据、保存与迁移

- 正常使用不要求注册或登录，核心日历任务流程可离线使用。
- 日任务与随笔按日期存为本地 JSON；长期任务、长期标签、提醒规则也保存到本地数据目录。
- 可在设置中查看实际数据路径、选择自定义文件夹，或恢复默认位置。
- 切换路径不会自动搬运旧文件；迁移时先复制数据，再切换到目标目录。
- 备份日程数据时退出应用，复制完整的当前数据目录；其中可能存在的提醒事务恢复文件也应保留。
- 主题透明度、内部剪贴板、设置页偏好等使用应用本地偏好存储；仅备份日程数据目录不等于导出这些界面偏好。
- 日任务采用延迟合并保存，切日、交接窗口和相关关闭动作会等待待保存内容。
- 同一窗口正在保存和后续待保存的内容会顺序完成，避免旧保存覆盖较新的输入。
- 提醒规则与日任务生成采用版本检查、事务日志和原子替换，减少中断及窗口竞争造成的不一致。
- 保存失败时提示并保留可重试的待保存内容或表单草稿。
- 品牌更新保留原应用标识与数据路径，不因更名重新创建一个空白数据目录。

## 十六、最适合介绍给用户的场景

| 场景 | 使用方式 |
| --- | --- |
| 每天工作、学习排程 | 在日视图列任务、拆子任务，完成后保留结果，写一段随笔 |
| 每周需要重复使用的工作清单 | 复制上次任务树到新日期，或从长期任务库手动安排 |
| 项目拆解与下一步行动 | 用任务树表达结构，折叠不需要看的分支，拖动调整顺序与层级 |
| 灵感、待办池、长期愿望 | 先放进长期任务库，确定时间后再安排到具体日期 |
| 生日、纪念日、周期事项 | 设置公历或农历重复提醒，按日期出现在日任务中 |
| 月度回顾与找回资料 | 看月历状态，用日期范围和关键词搜索任务、标签与随笔 |
| 需要持续看到待办的桌面工作 | 将日视图置顶、调整透明度，与主要工作窗口并排 |

## 十七、对外介绍时的准确边界

- 提醒按日期生成任务；没有按时分触发的系统弹窗、声音或应用退出后的后台闹钟服务。
- 没有内置账号云同步、多人协作、第三方日历同步；跨电脑使用依靠数据备份与迁移。
- 完成、失败统计是任务数量统计，不能宣传成已经实现耗时分析、打卡日历或趋势图表。
- 复制粘贴是应用内部的结构化任务复用；不应宣传为任意软件之间的任务剪贴板。
- 长期任务库是无日期清单；其安排记录独立，不是会自动同步所有日期任务的关联项目系统。
- 公历、农历支持用于重复提醒规则；不要宣传成已经支持完整农历月历、节气、法定节假日或调休数据。
- 当前发行目标为 Windows；其他平台的可安装版本需要单独验证与构建。
