# 开发与发行

## 本地启动

Windows 10/11 x64，准备 Node.js、Rust（MSVC）、Visual Studio C++ 构建工具与 WebView2。然后运行：

```powershell
npm ci
npm run dev
```

前端是原生 JavaScript ES Modules，无前端打包框架；`src/index.html` 是入口。Tauri 的 `frontendDist` 直接指向 `src/`。

## 目录

| 目录                        | 内容                                   |
| --------------------------- | -------------------------------------- |
| `src/domain/`               | 任务、日期、重复提醒、颜色及花丛等规则 |
| `src/storage/`              | 前端存储接口与保存队列                 |
| `src/ui/`                   | 拖拽、窗口、花丛等可复用交互           |
| `src/views/`、`src/styles/` | 页面与外观；设置统一由独立窗口承载     |
| `src-tauri/src/`            | 文件事务、数据迁移、窗口管理与原生 IPC |
| `tests/`                    | 单元测试和隔离浏览器回归               |
| `tools/screenshots/`        | README 的虚构场景与真实页面截图脚本    |
| `tools/perf/`、`tools/qa/`  | 性能与原生端隔离验证                   |
| `tools/release/`            | Windows 安装包及免安装压缩包生成       |

`com.example.desktop-calendar` 与既有存储键是兼容性标识，请勿只为美观更名，否则已有用户的数据路径会变化。

## 检查

```powershell
npm run check
npm test
npm run format:check
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

按修改范围运行相关浏览器回归，例如 `test:browser`、`test:calendar`、`test:settings`、`test:tags`、`test:botanical`、`test:garden`、`test:paper-polish`、`test:growth-refinements`。浏览器测试使用独立临时配置与合成数据。可通过 `CHROME_PATH` 指定 Chrome 可执行文件。

`npm run format` 统一 JavaScript、CSS、JSON 和 Markdown 格式；Rust 使用 `cargo fmt`。性能原始 JSON 不经过格式化。

原生数据迁移验证见[数据备份与迁移](数据备份与迁移.md)。测试构建使用随机独立应用标识和隐藏窗口，不接触实际日程。

## README 截图

```powershell
npm run screenshots
```

脚本渲染真实 `src/` 页面，生成 `docs/images/` 中的四张 PNG。演示日期固定为 2026-10-26，场景是一位年轻后端工程师，安排涵盖需求交付、Agent 与鉴权学习、生活采购和运动。日视图展开今日随笔，并展示 9 项已完成任务对应的花丛；截图前校验任务、随笔与花朵完整显示。完整文字稿见[截图示例计划](截图示例计划.md)。农历生日与周提醒由项目自身的规则生成。没有使用 AI 界面图或用户的私人记录，演示数据不会被打包到应用。

## Windows 发行

先完成检查、提交并推送 `main`，然后运行：

```powershell
npm run release:windows
```

脚本核对工作区干净且当前提交已在 `origin/main`，再构建 NSIS 安装包，并在忽略提交的 `release/` 下输出：

- `FloraGrid_<版本>_x64-setup.exe`：安装版。
- `FloraGrid_<版本>_windows-x64_portable.zip`：免安装版，内含程序和说明。
- `SHA256SUMS.txt`、`release.json`：校验值及对应源码提交。

也可单独运行 `npm run build` 构建安装包。原始输出位于 `src-tauri/target/release/bundle/nsis/`。

免安装版仍需要 WebView2，数据默认存放在用户目录，可以从设置中改位置。它和安装版使用同一个应用标识。请通过导出备份迁移数据，不要把“复制 exe”当作数据备份。

发布二进制前应核对安装包、压缩包内容与校验值。代码签名需要维护者自己的签名证书；仓库不保存凭据或私钥。
