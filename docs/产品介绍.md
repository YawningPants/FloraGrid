# 日枝 · FloraGrid

**让每一天，长出一点进展。**

早上，把今天要做的事放在桌面；遇到大任务，就拆成几步慢慢推进。常做的事收进长期任务库，下次直接加入日程；上次整理好的整套任务，也能连同子任务一起复制到另一天。

日枝把日历、待办和随笔放在一起：用月视图看安排，用标签和搜索找回记录，让公历或农历的生日、纪念日按期出现在日任务中。做完一件事，开一朵小花；工作时把小窗口置顶，结束时留下一段当天的想法。

不用注册，数据保存在本机。给事情一个落点，也给自己的每一天留一点生长的空间。

## 一句话介绍

日枝是一款支持树状任务、整树跨日复制、长期任务复用和公农历提醒的本地桌面日程工具。

## 发布页短版

把待办放在桌面，把大事拆成小步。做完一件事，开一朵小花。日枝支持树状任务、跨日期复制、长期任务库、公农历生日提醒与每日随笔；用月历看安排，用搜索找记录。五套自然主题，也可切换为原来的精简外观。无需注册，本地保存。

## 名称含义

- **日**：以每天为安排和回顾的基本单位。
- **枝**：对应树状子任务，也代表持续积累的小进展。
- **FloraGrid**：延续现有仓库名称，作为英文名；用生长与日历格子的意象呼应中文名。
- **品牌表达**：日枝 · FloraGrid。
- **短句**：让每一天，长出一点进展。

## Logo

日历轮廓代表日期；内部枝芽同时构成一个完成勾，表达从安排到行动的进展。深青底、暖白日历和雾青枝芽，与应用的海雾青主题呼应。无文字图形适合任务栏、托盘与小尺寸窗口图标。

提醒功能的对外表述应使用“按日期加入日任务”或“日任务提醒”；当前版本不提供应用退出后的定时通知。
