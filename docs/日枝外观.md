# 日枝外观与精简外观

**外观**（日枝 / 精简）与**窗口风格**（纸页笔记本 / 毛玻璃）可独立选择。首次使用默认为日枝与笔记本，已有用户的外观偏好继续保留。

## 两种外观

- **日枝**：任务是叶，父子关系是枝；完成任务时原位置开花。十种花型、六种花色随任务保存，日/月视图保持一致，历史记录加载时不重播动画。
- **精简**：使用对勾、连续的直角连接线和安静的任务层次。子任务同样不套独立边框。
- 根任务及子树共享窗格，自定义根任务色作用于整组左边缘；子任务颜色用于自己的文字和状态标记。
- 任务完成后立即平滑归位，父任务折叠与开花同时开始。恢复一个子任务为进行中时，已完成祖先递归恢复，统计及花丛一起更新。
- 根任务可展示与编辑标签；子任务标签的数据、继承、搜索和复制逻辑保留，界面入口由 `src/domain/task-presentation.mjs` 的开关控制。

## 五组配色

| ID      | 笔记本 | 日枝毛玻璃 | 精简毛玻璃 |
| ------- | ------ | ---------- | ---------- |
| morning | 奶油纸 | 枝间雾     | 海雾青     |
| mist    | 雾蓝笺 | 雨后蓝     | 暮云蓝     |
| apricot | 杏仁页 | 杏色光     | 暖杏棕     |
| sage    | 鼠尾草 | 苔庭绿     | 松影绿     |
| rose    | 玫瑰笺 | 暮花粉     | 雾玫灰     |

笔记本的颜色系统由 `src/domain/notebook-theme.mjs` 独立定义，组件样式在 `src/styles/notebook-paper.css`：纸面填色、墨线边缘、纸签标签与细叶脉；设置页没有装订线，任务区没有横线，随笔横线随内容滚动且位于字形下方。今天用浅字、深墨色方印标记。

笔记本花瓣使用明亮的金、粉、蓝、紫、杏和珊瑚色，不和绿色纸页主题混色。旧 `sage` 花色 ID 在纸面显示珊瑚色，任务数据不改写。失败使用独立砖红墨色，优先于用户自定义粉色，并保留失败符号及划线。

毛玻璃支持 34%～100% 的不透明度，笔记本采用不透明纸面。两个窗口风格都使用原 Logo；窗口标题栏、任务栏、托盘图标一致。

## 顶部花丛

“开启花丛”独立控制日视图顶部装饰，关闭后仍有任务旁开花动画。系统减少动态效果时使用静态花朵。

| 窗口宽度     | 总上限 | 前排 | 后排 |
| ------------ | -----: | ---: | ---: |
| 小于 360px   |     10 |    6 |    4 |
| 360–519px    |     14 |    8 |    6 |
| 520px 及以上 |     18 |   10 |    8 |

后排先绘制、花头更小且较淡；新增完成进入前排，只淘汰后排中较早的花。撤销完成或删除后优先从后排补位。六组共享 SVG 动画，位置缓存和备用锚点避免在同一位置明显换花；失焦、隐藏、最小化时暂停。

花丛不等于花田，没有月/年花朵统计。性能与测试方法见[两层花丛性能评估](performance/两层花丛性能评估.md)。

## 交互与验证

- 鼠标选色后不将焦点送回任务，键盘关闭调色盘后保留合理焦点；次要操作随悬停或键盘聚焦出现。
- 拖拽保留灰色原位置、真实目标预览、细边框和小指示器。失败/删除任务不可拖动；折叠父任务可接收新任务，提交前不修改数据，取消恢复原样。
- 同一 SVG 连接父任务与子树，按布局坐标更新；折叠期间保持 1:1 比例，避免动画 transform 造成断枝。
- 月历为主茎和每周枝条，非本月日期不跳转。提醒的日枝预览没有多余边框；纸面日期高亮不遮挡枝叶。
- “置顶”指窗口置顶，与任务置顶分开。错误和编辑限制在任务区底部显示，避开密集的顶部。

相关回归命令：`test:botanical`、`test:garden`、`test:paper-polish`、`test:growth-refinements`、`test:browser`、`test:settings`。它们使用独立浏览器配置与虚构数据。
