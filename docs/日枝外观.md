# 日枝外观与精简外观

入口：**设置 → 主题 → 外观**。默认使用日枝外观，选择精简即可恢复原来的五套颜色和完成对勾。不改变任务数据、日期或存储位置。

## 日枝外观

- 六种花型：五瓣野花、细瓣雏菊、心瓣花、圆瓣花、星瓣花、重瓣山茶；搭配米白、雾粉、浅蓝、淡紫、暖杏、鼠尾草绿六组花色。日视图约 420 ms 展开，月历使用 14 px 静态花头。
- 第一次完成时随机选花型与花色，保存为任务的可选 `flower: { variant, tone }` 字段。刷新、切主题、撤销再完成、日/月视图之间都保持一致；颜色会被当前主题轻微调和。历史任务按 ID 稳定生成，无需批量改写旧数据；主动撤销时保留当前花型，避免下次完成变样。
- 完成状态先写入现有保存队列，随后播放反馈；叶子任务约 440 ms 后按状态、置顶和原顺序归位。父任务先开花，再用约 280 ms 收起子树，折叠结束后归位。动画不是保存成功提示，保存失败继续由已有流程报告。
- 只替换发生变化的任务行，只移动状态改变的任务节点，保留其他卡片、滚动区域和焦点。
- 快速撤销会取消该朵花的展开；切换日期、搜索、切换外观或刷新会清理待执行的视觉操作。重新加载已完成任务不重播动画。
- 父任务完成时平滑折叠子树，支持动画过程中手动反向展开；未处理完子任务的限制保持。精简模式也修复自动折叠动画。失败、删除不使用枯萎或死亡意象。
- 日视图中一个根任务及其子树共用一个轻薄外轮廓；子任务去掉独立边框，用稍浅的文字与共享曲枝表示从属关系。指定的任务颜色用于文字与叶片，完成和失败保留各自的状态标记；普通标签、继承标签和调色盘仍可使用。
- 每个父子分组使用一个静态 SVG，细枝连接到任务的叶片标记，完成时在该位置开花。枝条随布局、折叠和拖拽预览更新，没有逐帧重画循环。
- 月历使用一个静态 SVG：主茎连接每周的细枝，空日期直接经过，有任务的日期长出分叉。任务去掉边框，颜色由文字和叶片表示。日期仍是完整点击区域，任务仍可点击定位与右键复制，超量任务仍显示数量。
- 随笔标题、长期任务与空状态继续使用主题枝芽。粘贴任务有一次短新叶反馈；标题、状态、标签、颜色和子树沿用原有复制规则，新任务 ID 使用新的花朵外观。
- 没有持续动画、粒子、额外窗口、图片下载或图形运行库；精简外观不创建花朵 SVG。

“完成时开花”可以关闭：只显示静态花朵。系统偏好减少动态效果时也跳过开花与归位动画。

## 主题

| 对应主题 ID | 日枝 | 精简（原配色） | 花色调和底色 |
| --- | --- | --- | --- |
| morning | 枝间雾 | 海雾青 | 米白 |
| mist | 雨后蓝 | 暮云蓝 | 雾青白 |
| apricot | 杏色光 | 暖杏棕 | 浅杏 |
| sage | 苔庭绿 | 松影绿 | 苔绿白 |
| rose | 暮花粉 | 雾玫灰 | 灰粉 |

保留主题 ID、透明度和原有本地存储键。新增 `appearance` 与 `completionMotion`；旧设置缺失这些字段时使用日枝外观、开启动效。两个外观使用同一个对应主题 ID 和透明度，切换后立即保存，并通过现有 Tauri 主题事件同步到打开的窗口。

## 验收

`npm run test:botanical` 用临时浏览器目录和虚构任务检查完成限制、原位展开、局部更新、保存、归位、折叠中间高度、快速撤销、历史花朵一致性、跨日期清理、减少动态效果、精简外观、五套主题、彩色子任务的继承标签与月历枝条，并输出实际截图到 `src-tauri/target/botanical-*.png`。

`tests/flowers.test.mjs` 检查随机覆盖、元数据兼容与持久化、旧任务稳定外观、复制后逻辑数据保持。

已有 `test:calendar`、`test:browser`、`test:settings` 分别覆盖日期/提醒、多窗口、拖拽、滚动与共享设置的回归行为。
